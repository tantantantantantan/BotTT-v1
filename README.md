# Selenium WebDriver Project

This project is a scaffold for using Selenium WebDriver in Python.

## Setup Instructions for Windows + VS Code

1. Install Python and necessary extensions for Visual Studio Code.
2. Clone the repository.
3. Navigate to the project directory in the terminal.
4. Run `pip install -r requirements.txt` to install dependencies.
5. To run the main application, call `python main.py`.

## Running Tests

Use any testing framework of your choice to run tests found under the `tests` directory.
